## Release 1.6.4

### Added
* **Multi-channel support**: the app now understands Steam, Epic Games, Microsoft Store, and itch.io installs: automatically detecting where your game lives and picking the right mod version for it.
* **Corsac Cosmetics** added to the mod store, bringing the total to 7 new mods.

### Improved
* **Freshened-up look**: mod cards, buttons, dropdowns, and checkboxes now have soft rounded corners that match the rest of the app's theme.
* **Redesigned version picker**: choosing a mod version opens a clean themed menu instead of a plain Windows dropdown.
* **Smarter filter bar**: fixed stray spacing on category pills, plus improved search that matches name, author, description, and more.
* **Modpack play**: pressing Play on a modpack now offers to install any missing mods instead of silently skipping them.
* **Smoother scrolling**: the version dropdown now scrolls with momentum.
* Faster startup — the Installed tab loads before the store finishes fetching.

### Fixed
* Updated mods not showing up due to Steam version of Among Us updating to x64 (authors merging Steam, Epic, and MS Store packing)
* Mods packaged with extra nested folders now install correctly instead of leaving the game unmodded.
* The Modpacks page now matches light mode properly.
* Fixed duplicate "mod selected" toolbar states and various theme-switch glitches.

**Full Changelog**: https://github.com/rewalo/BeanModManager/compare/v1.6.3...v1.6.4
